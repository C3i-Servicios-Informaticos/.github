# C3i Servicios Informáticos

> Partners tecnológicos para empresas de la Región de Murcia.

Empresa de servicios informáticos que desarrolla software a medida y ofrece soporte técnico, infraestructura y seguridad para empresas.

---

## Servicios

- **Desarrollo de software a medida** — aplicaciones de gestión y webs corporativas
- **Mantenimiento informático** — soporte técnico y gestión de infraestructura
- **Virtualización y teletrabajo** — soluciones para trabajar en remoto
- **Ciberseguridad** — protección y auditoría de sistemas
- **Digitalización** — automatización de procesos y facturación electrónica
